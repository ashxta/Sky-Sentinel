// Defect Classification

Four critical defect classes

Crack Detection
Detects hairline and structural cracks on fuselage, wings, and panels with bounding-box annotations and severity scoring.
Precision: 94%
Corrosion Mapping
Identifies oxidation and surface corrosion zones, mapping affected areas for prioritized MRO intervention.
Precision: 91%
Dent Identification
Locates impact dents and deformations on aircraft skin, flagging depth-risk areas for structural review.
Precision: 89%
Paint Degradation
Detects paint fade, peeling, and coating loss that may expose underlying metal to environmental damage.
Precision: 87%

// Project Plan

10-week POC roadmap

Structured sprint plan targeting a fully functional edge AI inspection demo on NVIDIA Jetson Nano. Each phase builds iteratively toward demo submission.

01
Weeks 1–2
Data Gathering & Labeling
Collect aerospace defect imagery from public NDT datasets. Label cracks, corrosion, dents, and paint degradation using Roboflow. Generate synthetic augmentation for class balance.
02
Weeks 3–4
Model Training & Initial Validation
Train YOLOv8n on curated dataset. Validate mAP across all defect classes. Apply Albumentations augmentation pipeline for robust generalization and transfer learning fine-tuning.
03
Weeks 5–6
Edge Optimization & Jetson Deployment
Export model via ONNX. Apply INT8 quantization with TensorRT for 4x compression. Deploy on NVIDIA Jetson Nano. Validate <100ms latency and 15–30 FPS inference in offline mode.
04
Weeks 7–10
Dashboard, Testing & Demo Submission
Build Streamlit inspection dashboard with live defect visualization. Implement SQLite logging and PDF/CSV report export. End-to-end testing and final demo preparation for submission.
